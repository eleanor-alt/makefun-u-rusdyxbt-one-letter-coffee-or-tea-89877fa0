Coffee is the more vivid answer in the coffee-against-tea argument: bitter, dark, urgent, the drink that drags a morning into being, while tea waits politely. And A is the top grade — the A-grade answer. A dependency-free Python program (standard library only), deterministic, writes exactly that one letter to `/output/entry.txt`.

python3 main.py  # writes /output/entry.txt (exactly one character: A)
